maxpolio 자동 저널 도구 설계와 구현

TL;DR: Claude Code 세션이 끝날 때마다 자동으로 기술 블로그형 저널과 강점 리포트를 만들어주는 개인 도구 "maxpolio"를 계획부터 구현까지 진행했다. 훅은 즉시 반환하고 분리된 워커가 일하게 했고, 결과물 UI는 직접 만들지 않고 Obsidian 볼트로 대체했다.

계획 단계에서 갈린 세 가지 결정

훅이 API 호출을 기다리면 세션 종료가 막힌다. 그래서 훅은 stdin만 읽고 바로 끝나게 했다. 스킵 기준은 git 변경 유무가 아니라, 분류 단계가 세션 내용을 보고 should_journal을 판단하게 바꿨다.

처음 계획에는 정적 HTML 대시보드가 있었는데, "옵시디언 같은 툴을 쓰면 어떨까, 이미 UI가 있으니까"라는 말에 대시보드를 통째로 빼고 출력 폴더를 그대로 Obsidian 볼트로 열 수 있게 했다. 만드는 것보다 안 만드는 쪽이 더 나은 결정이었다.

터미널 출력과 로그, 오른쪽 노트는 실제 실행 결과를 그대로 옮겨 재생한 것입니다. 로그와 리포트는 읽기 쉽게 일부만 남겼고, # 회색 기울임 줄은 설명용 주석입니다. 오른쪽 노트는 초기 설계 당시(2026.09)에 생성된 글입니다.
